    实验三 按钮控制LED-1#

    1. 概述#

      我们要结合数字输入功能，制作一个可控制的LED。实现按住按键时，点亮LED，放开按键后，熄灭LED的效果。实验中我们将用到按键或者按键模块，常见的有2脚按键和4脚按键，其内部如图所示。当按下按键时，就会接通按键两端，放开时，两端会再次断开。

      按键

    2. 实验所需材料#

      Arduino UNO、面包板、LED一个、按键一个、220Ω电阻一个、10KΩ电阻一个

    3. 连接示意图#

      按键控制LED实验连接示意图

    4. 原理图#

      按键控制LED实验原理图

    5. 硬件知识要点#

      如图所示，我们使用了两个电阻。LED的一端，我们使用了220Ω的电阻，按键一端，我们使用了10K的电阻，两个电阻的作用分别如下：

      限流电阻：

      一般LED的最大能承受的电流为25mA，如若直接将LED连接到电路中，当点亮LED时，很容易烧毁LED。如图2-24所示，我们在LED一端串联了一个电阻R2，这样做可以减小流过LED的电流，防止损坏LED。这个电阻我们称之为限流电阻。

      下拉电阻：

      在Arduino 控制器2号引脚到GND之前，我们连接了一个阻值很大（10K）的电阻。如果没有该电阻，当未按下按键时，2号引脚会一直处于悬空状态，此时使用digitalRead() 读取2号引脚状态，会得到一个不稳定的值（可能是高，也可能是低）。添加这个R1电阻到地就是为了稳定引脚的电平，当引脚悬空时，就会识别为低电平。而这种将某节点通过电阻接地的做法，叫做下拉。这个电阻叫做下拉电阻。

      实现方法分析：

      当未按下按键时，2号引脚检测到的输入电压为低电平；当按下按键时，会导通2号引脚和VCC，此时2号引脚检测到的输入电压为高电平。通过判断按键是否被按下，来控制LED的亮灭。

    6. 程序编写#

      你可以在IDE的文件菜单>示例>02.Digital>Button中找到以下程序：

      /*
  Button
  通过2号引脚连接的按键，控制13号引脚连接的LED
  备注：大多数Arduino的13号引脚上都连接了名为L的LED。

  created 2005
  by DojoDave <http://www.0j0.org>
  modified 30 Aug 2011
  by Tom Igoe

  This example code is in the public domain.
  http://www.arduino.cc/en/Tutorial/Button
*/

// 硬件引脚定义
const int BUTTON_PIN = 2;  // 按键输入引脚
const int LED_PIN = 13;    // LED输出引脚

// 全局变量：存储按键状态（0=未按下，1=按下）
int buttonState = 0;

/**
 * 初始化函数：板子启动后仅执行一次
 */
void setup() {
  // 配置LED引脚为输出模式
  pinMode(LED_PIN, OUTPUT);
  // 配置按键引脚为输入模式
  pinMode(BUTTON_PIN, INPUT);
}

/**
 * 主循环函数：初始化完成后循环执行
 */
void loop() {
  // 读取按键引脚的电平状态
  buttonState = digitalRead(BUTTON_PIN);

  // 根据按键状态控制LED亮灭
  if (buttonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);  // 按键按下，点亮LED
  } else {
    digitalWrite(LED_PIN, LOW);   // 按键松开，熄灭LED
  }
}

    1. 实验三 按钮控制LED-2#

    2. 概述#

      根据电路原理，修改连接方式并使用上拉电阻实现的按钮控制LED。

    3. 连接示意图#

      如图所示，我们去掉了原来电路中2号引脚连接的下拉电阻，并将按键的一端连接到GND。

      按键控制LED实验2连接示意图

    4. 原理图#

      按键控制LED-2实验原理图

      同时，我们需要将原程序setup() 部分中的pinMode(buttonPin,INPUT);修改为pinMode(buttonPin,INPUT_PULLUP);这样能使能该引脚上的内部上拉电阻，等效于在该引脚到VCC之间连接了一个阻值为20K～50K的电阻。

    5. 硬件知识要点#

      上拉电阻同下拉电阻一样，可以稳定I/O口电平，不同的是电阻连接到VCC，将引脚稳定在高电位。这种电阻叫做上拉电阻。这里我们使用的是内部上拉电阻，你也可以使用外部上拉电阻替代。

      稳定悬空引脚的电平所用电阻应该尽量选择较大的阻值，我们一般使用10K电阻。

    6. 程序编写#

      修改后的程序代码如下：

      /*
OpenJumper Button Module
按键控制LED（上拉输入模式）
www.openjumper.com
*/

int buttonPin = 2;
int ledPin = 13;
int buttonState = 0;  // 存储按键引脚电平状态

void setup() {
  // 初始化引脚模式：按键上拉输入，LED输出
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 读取按键引脚电平（上拉模式：未按下=HIGH，按下=LOW）
  buttonState = digitalRead(buttonPin);

  // 按键按下时点亮LED，松开时熄灭
  if (buttonState == HIGH) {
    digitalWrite(ledPin, LOW);
  } else {
    digitalWrite(ledPin, HIGH);
  }
}

    1. 实验三 按钮控制LED-3#

    2. 概述#

      接下来我们要对控制程序做一个升级，完成一个新的控制效果。按一下按键，点亮LED；再按一下按键，熄灭LED，实现一个新的按键控制方式。

    3. 连接示意图#

      同实验二图

      按键控制LED实验3连接示意图

    4. 硬件知识要点#

      下载该程序，每按一下按键，LED状态都会改变。以上程序中，使用了while(digitalRead(buttonPin)==HIGH{}

      悬空：没有连接任何电路

      因为在初始化时，我们已经将buttonPin引脚设为了输入上拉状态。如果没有按下按键，使用digitalRead(buttonPin) 读出的值始终为高电平，这个循环也将一直运行；当你按下按键后，digitalRead(buttonPin) 读出了低电平，while循环的判断条件为假，程序会退出这个循环，并开始运行此后的语句。这样我们就实现了一个等待用户按下按键的效果。

      程序末尾有一个delay(500) 的延时，它在这里是极其重要的。你可以尝试删去这个延时操作，再下载程序到Arduino。你会发现按键经常出现控制失灵的情况。这是因为程序运行的非常快，没有了延时操作，你按下按键到放开按键的间隔时间虽然极短，但loop中的语句可能已经运行了很多次，很难确定你放开按键时正在运行的loop() 循环是点亮还是熄灭LED。正是这样的原因，程序变得不那么好用了。

      上面程序中，我们使用延时操作来使两次按键间产生一定的间隔时间，在间隔时间内Arduino会忽略按键按下情况，从而达到区分两次按键的目的。

    5. 程序编写#

      修改后的程序代码如下：

      /*
OpenJumper Button Module
按键控制LED（按下切换LED状态）
www.openjumper.com
*/

int buttonPin = 2;
int ledPin = 13;
boolean ledState = false;  // LED状态标记：false-灭，true-亮
boolean buttonState = true; // 按键状态缓存（初始为上拉默认高电平）

void setup() {
  // 初始化引脚模式：按键上拉输入，LED输出
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 等待按键按下（上拉模式下按下为LOW，未按下为HIGH）
  while (digitalRead(buttonPin) == HIGH) {}

  // 切换LED状态
  if (ledState == true) {
    digitalWrite(ledPin, LOW);
    ledState = !ledState;
  } else {
    digitalWrite(ledPin, HIGH);
    ledState = !ledState;
  }

  // 延时消抖，避免单次按下多次触发
  delay(500);
}
