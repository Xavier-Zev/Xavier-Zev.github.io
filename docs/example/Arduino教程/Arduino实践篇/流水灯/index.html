    实验二 流水灯#

    1. 概述#

      在上一章中我们进行了板载LED的实验，对于Arduino的语言与Arduino IDE的使用方法有了一个简单的认识，在这一章中，我们将开始搭建我们的第一个电路，准备好需要的实验器材，让我们开始Arduino的学习之旅吧。

    2. 实验材料#

      UNO 控制板一块，LED灯6个，220Ω电阻6个，面包板1块，面包板跳线若干。

    3. 连接示意图#

      流水灯实验连接示意图

    4. 硬件连接图#

      流水灯实验硬件连接图

    5. 硬件知识要点#

      LED的两个针脚一长一短，其中长的连接的是正极，而短的连接的是GND，其次，在LED与控制板之间，需要添加一个限流电阻，由于LED内阻较小，不添加限流电阻的话有可能会烧坏LED。

    6. 程序编写#

      // 定义LED引脚范围常量（增强代码可读性和可维护性）
const int LED_START_PIN = 2;  // LED起始引脚
const int LED_END_PIN = 7;    // LED结束引脚

// 板子启动/复位后仅运行一次的初始化函数
void setup() 
{
  // 初始化I/O口：将引脚2到7全部设置为输出模式
  for (int i = 2; i < 8; i++) 
  {
    pinMode(i, OUTPUT);  // 每个pinMode调用单独一行，增加代码可读性
  }
}

// 初始化完成后循环执行的主函数
void loop() 
{
  // 正向流水：从引脚2到引脚6，逐个点亮LED，亮1秒后熄灭
  for (int i = LED_START_PIN; i < 6; i++) 
  {
    digitalWrite(i, HIGH);  // 点亮当前引脚的LED
    delay(1000);            // 保持点亮状态1秒（1000毫秒）
    digitalWrite(i, LOW);   // 熄灭当前引脚的LED
  }

  // 反向流水：从引脚7到引脚3，逐个点亮LED，亮1秒后熄灭
  for (int i = LED_END_PIN; i > 2; i--) 
  {
    digitalWrite(i, HIGH);  // 点亮当前引脚的LED
    delay(1000);            // 保持点亮状态1秒（1000毫秒）
    digitalWrite(i, LOW);   // 熄灭当前引脚的LED
  }
}
