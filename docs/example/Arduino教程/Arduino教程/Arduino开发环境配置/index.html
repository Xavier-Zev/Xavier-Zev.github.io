    Arduino - 环境配置#

    了解Arduino UNO 板的主要部件后，我们就可以学习如何设置 Arduino IDE 了。一旦我们学会了这一点，我们就可以准备将我们的程序上传到 Arduino 板上了。在本节中，我们将通过简单的步骤学习如何在我们的计算机上设置 Arduino IDE 并准备电路板通过 USB 电缆接收程序。

    具体流程#

    1. Step1-硬件准备#

      首先，您必须有 Arduino 电路板（您可以选择您最喜欢的电路板）和 USB 电缆。如果您使用 Arduino UNO、Arduino Duemilanove、Nano、Arduino Mega 2560 或 Diecimila，您将需要一条标准 USB 线（A 插头转 B 插头），就像您连接到 USB 打印机的那种，如下图所示。

      如果您使用 Arduino Nano，您将需要一条 A 转 Mini-B 线，如下图所示。

    2. Step2-下载 Arduino IDE 软件#

      您可以从 Arduino 官方网站上的下载页面获取不同版本的 Arduino IDE。您必须选择与您的操作系统（Windows、IOS 或 Linux）兼容的软件。文件下载完成后，解压缩文件。

    3. Step3-启动电路板#

      Arduino Uno、Mega、Duemilanove 和 Arduino Nano 自动从 USB 连接到计算机或外部电源获取电力。如果您使用的是 Arduino Diecimila，则必须确保电路板配置为从 USB 连接获取电力。使用跳线选择电源，跳线是一小块塑料，可安装在 USB 和电源插孔之间的三个引脚中的两个上。检查它是否位于最靠近 USB 端口的两个引脚上。

      使用 USB 电缆将 Arduino 电路板连接到计算机。绿色电源 LED（标有 PWR）应亮起。

    4. Step4-启动 Arduino IDE#

      下载 Arduino IDE 软件后，您需要解压缩文件夹。在文件夹中，您可以找到带有无穷大标签的应用程序图标（application.exe）。双击图标以启动 IDE。

    5. Step5-打开第一个项目#

      软件启动后，您有两个选项 :

      1）创建一个新项目。

      2）打开现有项目示例。

      要创建新项目，请选择文件 → 新建。

      要打开现有项目示例，请选择文件 → 示例 → 基础知识 → Blink。

      在这里，我们只选择一个名为Blink的示例。它会在一定时间延迟后打开和关闭 LED。您可以从列表中选择任何其他示例。

    6. Step6-选择 Arduino 电路板#

      为避免在将程序上传到电路板时出现任何错误，您必须选择正确的 Arduino 电路板名称，该名称与连接到计算机的电路板相匹配。

      转到工具 → 电路板并选择您的电路板。

      在这里，我们根据我们的教程选择了 Arduino Uno 电路板，但您必须选择与您使用的电路板匹配的名称。

    7. Step7-选择串行端口#

      选择 Arduino 电路板的串行设备。转到 工具 → 串行端口 菜单。这可能是 COM3 或更高版本（COM1 和 COM2 通常保留用于硬件串行端口）。要找出答案，您可以断开 Arduino 电路板并重新打开菜单，消失的条目应该是 Arduino 电路板的条目。重新连接电路板并选择该串行端口。

    8. Step8-将程序上传到主板#

      在解释如何将程序上传到主板之前，我们必须演示 Arduino IDE 工具栏中出现的每个符号的功能。

      A − 用于检查是否存在编译错误。

      B − 用于将程序上传到 Arduino 主板。

      C − 用于创建新草图的快捷方式。

      D −用于直接打开示例草图之一。

      E − 用于保存草图。

      F − 串行监视器用于从电路板接收串行数据并将串行数据发送到电路板。

      现在，只需单击环境中的"上传"按钮。等待几秒钟；您将看到电路板上的 RX 和 TX LED 闪烁。如果上传成功，状态栏中将显示"上传完成"消息。

      注意 − 如果您有 Arduino Mini、NG 或其他电路板，则需要在单击 Arduino 软件上的上传按钮之前立即按下电路板上的重置按钮。
